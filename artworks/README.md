# Artworks-Ordner (`artworks/`)

Dies ist der **einzige zentrale Ordner** für alle fertigen, handgezeichneten Grafiken des Spiels.

> **Wichtig:** Alle Dateien hier sind **optional**.  
> Solange eine Grafik noch nicht vorhanden ist, zeigt das Spiel automatisch saubere, eingebaute Vektor-Illustrationen — es gibt keine Fehlermeldungen oder leeren Kästen.  
> Sobald du eine fertige Datei mit dem **exakten Dateinamen** in den passenden Unterordner legst, übernimmt das Spiel sie beim nächsten Build automatisch.
